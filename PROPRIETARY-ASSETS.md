# Production-only proprietary assets

This public repository deliberately excludes paid assets licensed for the
production Dimitrium.org site only. They are not covered by the AGPL software
license or the content licenses in this repository.

Excluded paths:

- `wp-content/uploads/fonts/Minicomputer-*.ttf` — the Minicomputer font family;
- `wp-content/plugins/dimitrium-now-playing/assets/icons/` — menu and close
  icons;
- `wp-content/uploads/social-icons/` — social and interface SVG icons.

To run a fork, use assets you are licensed to use, or replace the corresponding
CSS, block markup, and WordPress media references with freely licensed
alternatives. Do not copy these assets from the production site into a fork.
